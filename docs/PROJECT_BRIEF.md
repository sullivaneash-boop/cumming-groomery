# Project brief

Peakline Media built this independent sales demonstration for Shelby at The Cumming Groomery. The owner has expressed interest in pricing. Commissioning, approval and endorsement remain outstanding.

The website should help a pet owner quickly determine whether the salon grooms their type of pet, get a feel for the business, and call or continue to the current appointment provider. The mobile experience leads with both appointment and phone actions. The five routes are Home, Services, Gallery, About and Visit.

Use a warm boutique direction with actual salon photos supplied for the demo. Keep service examples and unapproved content identifiable. The business's current Pawfinity workflow remains the system for intake and client management. The website needs no new hosted database, custom scheduler or payments.

The initial build uses Next.js App Router, TypeScript, Tailwind CSS and locally hosted assets. Typed data modules make later editing or a lightweight CMS possible. The local Git checkout is linked to the public GitHub repository supplied by Peakline Media. Keep review materials and supplied photos local or in an approved private preview until photo permissions and public launch are agreed.
