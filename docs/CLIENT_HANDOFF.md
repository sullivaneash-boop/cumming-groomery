# Client handoff

The website helps customers see the salon, explore grooming and get in touch. Appointment and client information stay in the salon's existing Pawfinity account.

| What to update | Where it lives |
| --- | --- |
| Salon name and contact details | Business content file |
| Appointment link, announcement or gift card | Site settings file |
| Services and frequently asked questions | Services and FAQ files |
| Featured photos and gallery | Gallery content file and image folder |
| Approved staff and customer reviews | People content file |

Peakline Media can make those edits as needed. If Shelby prefers to update photos or services directly, a small content editor can be added after discussing who will use it and how often.

For launch, send the approved services and hours, booking instructions for new and existing clients, public profile links and preferred photos. Confirm permission before using customer photos and reviews. A short screen share can cover the mobile visit, booking link and future updates. Share business account access through owner-managed roles where needed.
